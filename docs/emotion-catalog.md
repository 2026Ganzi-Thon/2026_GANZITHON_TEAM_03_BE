# 감정 기본 데이터

프론트 요청의 감정 7개를 V12__seed_emotions.sql로 추가합니다.

| 표시 순서 | code | name |
| --- | --- | --- |
| 1 | JOY | 기쁨 |
| 2 | SADNESS | 슬픔 |
| 3 | REGRET | 아쉬움 |
| 4 | FEAR | 두려움 |
| 5 | TIRED | 지침 |
| 6 | ANXIETY | 불안 |
| 7 | CALM | 평온 |

신규 항목은 활성 상태로 등록하며 ID는 DB가 발급합니다. 동일한 코드 또는 이름으로 수동 등록한 항목은 ID·코드·이름·표시 순서·활성 상태를 보존합니다. 기존 감정 기록이 참조하는 ID를 교체하지 않습니다. 프론트는 GET /api/v1/emotions에서 받은 ID를 사용합니다.

V10(고민 제목)·V11(섬 꾸미기) 작업과 번호 충돌을 피하도록 V12를 사용합니다. 배포 DB에 더 높은 버전이 먼저 적용되지 않도록 V10 → V11 → V12 순서를 다른 담당자와 맞춥니다. 이 브랜치는 돌봄 변경 없이 최신 develop에서 분리했습니다.

검증은 전용 로컬 MySQL에서 기본 데이터 생성, 수동 설정 보존, 재실행 시 중복 방지와 기존 감정 API를 확인합니다. 테스트용 감정은 기본 데이터와 다른 ID·코드를 사용합니다.
